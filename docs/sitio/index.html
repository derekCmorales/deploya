Instálalo en tu servidor

Guía completa →

El mismo Deploya que corre en la nube, en tu máquina y sin cobro. Licencia AGPL-3.0: tus contenedores y tus datos son tuyos.

  • Ubuntu · 2 vCPU · 4 GB
  • Docker 24+ y Compose v2
  • Tu dominio y *.tu-dominio hacia el servidor
  • Puertos 80 y 443
  1. Clona el repositorio 
    git clone https://github.com/derekCmorales/deploya.git && cd deploya
  2. Corre el instalador

    Comprueba requisitos, DNS y certificado antes de tocar nada; genera los secretos y levanta los servicios. Si una etapa falla, corriges y retomas con --continuar.

    ./scripts/instalar.sh
  3. Termina en el navegador

    Abre https://<tu-dominio>/configurar con el código que imprime el instalador (vale 30 minutos): creas el administrador, pruebas el correo y eliges quién puede registrarse.

¿Sin token DNS? Usa --sin-comodin y el certificado sale por HTTP-01. Actualizar y respaldar →
